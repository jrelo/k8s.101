# k8s.101

A single file, browser-based Kubernetes YAML generator and editor.

## What it does

Generate new YAML or load an existing file to edit. Supports Deployment, Service, ConfigMap, Ingress, and CronJob. Live preview updates as you type, with syntax highlighting in the output pane.

## Themes

Cycle through `minima` / `ocean` / `coast` with the theme button in the top right. Feel free to open a PR with new ones!
